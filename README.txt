Redox Dosimetry Lab: phone upload version (all files in one folder, no subfolders)

Upload every file in this folder to a public GitHub repo, turn on Pages (Settings > Pages > main branch, / root),
then open the link GitHub gives you in Safari (iPhone) or Chrome (Android) and add it to your home screen.

Updating later: upload the new index.html and sw.js over the old ones. The footer of the app shows the build number.
